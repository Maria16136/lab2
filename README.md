# Потоковый анализатор файлов

## Описание проекта

Программа предназначена для анализа файлов с событиями - записями о работе разных частей программы.
Она читает данные из CSV и JSONL файлов, проверяет их корректность и собирает общую статистику.

Программа умеет:

* читать один или несколько входных файлов;
* проверять обязательные поля и формат даты и времени;
* считать общее количество событий;
* подсчитывать количество событий каждого уровня важности;
* считать количество событий от каждого источника;
* находить пять источников с наибольшим количеством ошибок;
* определять время первого и последнего события;
* сохранять результат в JSON-файл.

Если во входных данных есть ошибка, программа по умолчанию прекращает работу и сообщает, 
в каком файле и на какой строке она находится. С помощью параметра `--skip-invalid` можно пропускать некорректные записи 
и продолжать анализ. Количество пропущенных записей сохраняется в отчёте.

## Форматы входных файлов

Программа поддерживает два формата.

### CSV

В CSV-файле первая строка содержит названия полей, а следующие строки - сами события.

Пример:

```csv
timestamp,level,source,message
2026-10-26T10:00:00,INFO,auth,User logged in
2026-10-26T10:05:00,ERROR,database,Connection failed
```

### JSONL

В JSONL-файле каждое событие записывается в отдельной строке в формате JSON.

Пример:

```jsonl
{"timestamp":"2026-10-26T10:00:00","level":"INFO","source":"auth","message":"User logged in"}
{"timestamp":"2026-10-26T10:05:00","level":"ERROR","source":"database","message":"Connection failed"}
```

В каждом событии должны присутствовать четыре поля:

* `timestamp` - дата и время события в формате ISO 8601;
* `level` - уровень важности: `DEBUG`, `INFO`, `WARNING`, `ERROR` или `CRITICAL`;
* `source` - название источника события;
* `message` - текст сообщения.

## Установка и запуск

Для установки проекта и необходимых инструментов разработки выполните команду из папки проекта:

```bash
python -m pip install -e ".[dev]"
```

### Анализ JSONL-файла

```bash
python -m streamstats analyze events.jsonl --format jsonl --output report.json
```

### Анализ CSV-файла

```bash
python -m streamstats analyze events.csv --format csv --output report.json
```

### Анализ нескольких файлов

```bash
python -m streamstats analyze first.jsonl second.jsonl --format jsonl --output report.json
```

Все входные файлы в одной команде должны иметь указанный формат.

### Пропуск некорректных записей

```bash
python -m streamstats analyze events.jsonl --format jsonl --output report.json --skip-invalid
```

Результат анализа сохраняется в файл `report.json`.

## Отчёт

Отчёт сохраняется в формате JSON и содержит следующие данные:

* `total_events` - общее количество обработанных событий;
* `level_counts` - количество событий каждого уровня важности;
* `source_counts` - количество событий от каждого источника;
* `top_error_sources` - до пяти источников с наибольшим количеством событий уровня `ERROR` и `CRITICAL`;
* `first_timestamp` - время первого события;
* `last_timestamp` - время последнего события;
* `skipped_records` - количество пропущенных некорректных записей.

Если событий нет, время первого и последнего события будет равно `null`.
Если при запуске не использовался параметр `--skip-invalid`, значение `skipped_records` будет равно нулю.

## Особенности реализации

Программа обрабатывает файлы последовательно, а не загружает весь файл в память сразу.
Это позволяет работать с большими файлами.

Для обработки ошибок используются отдельные классы исключений.
При пропуске некорректных записей программа выводит предупреждения в журнал.
Автоматические тесты проверяют работу анализатора, обработку ошибок и основные команды запуска.
